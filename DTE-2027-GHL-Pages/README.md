# Dance Teacher Expo 2027 — GoHighLevel Page Codes

All pages are built for GoHighLevel custom code elements and carry the DTE 2027 brand
(ink `#171114`, pink `#E23480`, fonts Anton / Montserrat / Caveat).

## Files

| File | What it is | Where it goes |
|---|---|---|
| `1-save-the-date-page.html` | Save-the-date page with photo strip (3 GHL-hosted images) | One custom code element on the save-the-date page |
| `2-vendor-prospectus-page.html` | Full vendor prospectus — packages aligned side-by-side, all 3 booking buttons → `vendor.danceteacherexpo.com.au/2027deposit` | One custom code element on the vendor page |
| `3-order-page-top-section.html` | Hero above the two-step order form. Also carries the page-wide dark background + the pink re-skin of the native form | Custom code element ABOVE the order form |
| `4-thank-you-page.html` | Post-payment page: tick, "Your stall is locked in", What happens next, footer | One custom code element on the thank-you funnel step |
| `5-404-error-page.html` | 404 page ("This page missed its cue") — home button → danceteacherexpo.com.au | One custom code element on the 404 page |
| `DTE27-email-signature-800x400.png` | 2027 email signature banner (retina) | Email signatures |
| `DTE27-email-signature-400x200.png` | Same, at the original 400×200 size | Email signatures |
| `email-signature-source.html` | Editable source for the signature banner | Keep for future edits |

## GHL setup checklist (every page)

1. Paste the whole file into a single **Custom Code** element.
2. Set the section to **Full Width** and zero the padding on section / row / column.
3. Set the page background colour to `#171114` in page settings.
4. Publish and check the **live URL** (not the builder preview).

Note: the order page needs only file 3 above the form — the old "bottom section"
content now lives on the thank-you page (file 4), so don't use both or it will
appear twice.
